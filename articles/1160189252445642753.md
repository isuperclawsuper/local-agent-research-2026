当大模型走出概念验证，真正进入企业实际业务场景时，两个现实问题随之涌现：在面临企业专业场景时，智能体难以实现针对性的能力匹配，导致在员工看来，智能体还停留在“能看不能用、能答不能落”阶段。

其次，借势过去一两年热潮，有些企业一口气打造了十几个智能体，但能用哪个？该用哪个？什么时候用哪个？员工还没开始用，就得先自己解一道选择题。

有没有一款智能体，既能深钻企业专业业务场景，又能不止于问答实现执行串联，同时还能针对企业已经完成部署的关联产品能力进行融合？

**6 月 23 日，2026 火山引擎 Force 原动力大会数据智能论坛**将升级发布企业级数据原生智能体 Data Agent Pro。作为企业数据消费与决策的统一智能入口，Data Agent Pro 不但能深度理解企业数据语义、指标口径和业务上下文，还能结合企业知识引擎、高质量数据集，甚至接入业务场景下的关联 Skills、Tools，完成从**任务理解、分析规划、数据调用、洞察生成**到**业务执行**的完整链路。

同时，Data Agent Pro 还提供针对智能体本身的运营分析能力，可帮助企业及员工**全链路监测任务链路，分析策略效果**，并将每一次任务路径都加以**沉淀反哺智能体持续调优。**

此外，论坛还将重点介绍 Agent 时代下的数据基础设施 **Agent DataLake**，聚焦多模态处理算子，拆解不同算子在企业不同业务场景下，如何将 Token 变成数据处理的新范式。

更有 **Talking Data、得物、广发证券、深势科技、商汤科技 Seko、中国美术学院等嘉宾**分享数据智能论坛 在企业内部落地经验，更多精彩内容，敬请锁定 6 月 23 日 2026 火山引擎 Force 原动力大会数据智能论坛直播间。
