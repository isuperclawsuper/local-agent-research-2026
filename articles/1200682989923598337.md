🎉 7 月 14 日，Cube Sandbox 的 GitHub Star 数，正式突破 10,000+了。

从第一行代码到今天，我们始终在做同一件事：为 AI Agent 打造一个更安全、更快、更可靠的执行环境。这条路并不算热闹，但每一次有人点亮那颗 Star，我们都真切地感受到——原来有这么多人，和我们看向同一个方向。

对你来说，Star 也许只是一次轻轻的关注；

但对我们来说，它是一份厚爱，一份信任，

也是 Cube 持续投入开源、认真打磨每一个技术细节的重要动力。

10,000 不是终点，而是一个新的起点。支持基于k8s集群部署、一键terraform集群安装、持续迭代和打磨 Cube 的核心竞争力……我们想做的还有很多，也希望能和更多人一起，把 AI Infra 的运行底座做得更扎实。

谢谢每一位看见我们、使用我们、给我们提 PR 和 Issue、陪我们一路走到这里的朋友。

我们会继续在开源世界里，认真地把每一块「积木」搭好。👇

欢迎访问 Cube GitHub 仓库：<https://github.com/TencentCloud/CubeSandbox>
