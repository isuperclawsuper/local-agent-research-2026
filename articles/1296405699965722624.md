云栖大会 Skill 正式上线千问 AI 平台。4 大展馆、120 多场分论坛，一句话帮你逛展台、听论坛。

先安装，再直接问

云栖大会 Skill 基于开放的 Agent Skills 标准开发，Codex、OpenClaw、Claude Code、Cursor 等支持 Skills 的 Agent 都能用，推荐千问办公和 Qoder。

打开你常用的 Agent，在对话框中输入并发送：

```
复制代码  
  
  
npx skills add QianWen-AI/apsara-conference-2026
```

按照提示完成安装后，直接用自然语言提问，不需要再记命令。例如：

* "有哪些 Agent 相关论坛值得看？"
* "帮我订阅这几场论坛。"
* "智能馆有哪些值得看的展台？"
* "我订的论坛有没有摘要可以领取？"

展馆怎么逛，

先让 Agent 帮你找重点

你可以从技术方向、行业兴趣或具体产品出发，让 Agent 查询展馆、展区和展台信息。想看 Agentic 应用、模型、算力，或者关注游戏、零售、汽车等行业，都可以直接问。到了现场，这能帮你少走弯路，把时间留给真正想看的展台；不在现场，也能先弄清楚各馆展示什么、哪些内容和自己有关。

论坛撞期，先筛选再取舍

面对密集议程，可以让 Agent 按时间、地点、主题和技术方向筛选论坛，查看具体议题，并订阅想参加或想继续跟进的场次。多个论坛撞期时，不必只看标题做选择。先了解每场讲什么，再决定哪场必须亲自去，哪场留待会后补课。对于已开放摘要服务的论坛，结束约 3 小时后可领取内容摘要，还可以继续追问核心观点、重要发布和技术亮点。

到不到现场，都能继续跟进

除了展馆和论坛，云栖大会 Skill 还可以查询直播，以及交通、住宿、餐饮、门票和签到等参会信息。它不会代替你到现场交流和体验，但可以帮你提前找方向、现场查信息、会后补内容。人负责交流、体验和判断，Agent 负责找、筛、记和补。9 月 22 日至 24 日，调用云栖大会Skill，带着 Agent 一起参加 2026 云栖大会。
