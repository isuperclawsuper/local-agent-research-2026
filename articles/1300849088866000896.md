让 Agent 整理客户反馈、生成分析报告，已成为不少团队尝试 AI 办公的起点。但围绕这份报告，仍有一系列工作需要人完成：把资料上传给 Agent，把结果下载下来，再发给同事审阅；同事补充最新数据后，又要重新交给 Agent。

**报告分析可以交给 AI，文件的交接却仍依赖人工。**

如果 Agent 能直接使用团队的项目文件夹呢？

Agent 从这里读取资料，将报告保存到这里；同事也从这里打开报告并修改。团队沿用熟悉的工作方式，Agent 遵循相应的权限规则。

这正是**火山引擎 ADrive 智能网盘**要连接的协作流程。

**让团队的项目空间，也成为 Agent 的工作空间**

让 Agent 参与项目，需要把资料准备、文件处理、成果审阅和访问管理连接起来。ADrive 智能网盘围绕这几个环节，让同一个项目空间承载团队与 Agent 的工作。

**统一空间：项目资料与任务成果，集中管理**

原始资料、分析草稿和最终报告，均可保存在 ADrive 的同一项目空间里。团队在这里整理资料、审阅结果；Agent 从这里读取任务所需文件，并将生成的成果保存至项目空间。

**本地挂载：熟悉的文件夹，人和 Agent 共用**

项目空间可通过 ADrive 企业版网盘挂载为本地盘符，像打开熟悉的普通文件夹一样。团队成员继续用桌面应用查看和编辑文件，接入后的 Agent 在项目文件夹中读取和写入。**同一项目文件夹，连接 AI 的处理过程与同事的后续工作。**

**成果协作：在线查看、版本恢复，交付更从容**

报告生成后，同事可通过在线预览查看内容；修改过程中，如需找回先前内容，可查阅历史版本并按需恢复。成果需分享给项目之外的协作者时，可通过链接分享，设置外链有效期、密码及下载权限等，以此管理分享方式。**从审阅到修改，再到交付，同一份文件贯穿全程，协作更顺畅。**

**权限与追溯：访问有边界，操作有记录**

文件交给 Agent 处理时，权限规则仍然生效：哪些资料可以读取、哪些位置允许写入，由身份与权限配置决定。相关操作留有审计记录，方便追溯谁在什么时间对哪些文件进行了什么操作。**团队可以开放任务所需的资料，同时保留清晰的访问边界。**

**少传一次文件，就少一次协作中断**

以客户反馈分析为例，项目文件夹中已有近期反馈和历史报告。过去，这些资料需要被挑选、打包，再作为附件交给 Agent；使用 ADrive 后，Agent 可在授权范围内直接读取项目文件。

报告生成后，交接方式也随之改变。成果保存在项目共享文件夹中，成员按权限查看或编辑，后续任务可直接读取，无须再为转交报告另行下载附件。文件交接少一些，团队就能把更多精力放在内容本身。

对企业而言，让 Agent 直接访问资料，还须明确它的操作范围。ADrive 通过身份与目录权限管理访问范围，并提供操作审计。参与一个项目，不等于可以读取其他项目；获准读取资料，也不等于可以任意修改。

**协作无中转，授权仍明确**——当企业把 Agent 从个人尝试带入团队日常工作，这两点必须同时解决。
