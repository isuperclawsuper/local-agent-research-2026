首先自报家门，官号小编是一个近 00 后文科生，完整地经历过 Python 自学从入门到放弃的全流程，至今基本只会写几句 Hello World、name lb = sb 等等的代码片段，从未独自实现过一个功能甚至 demo。

各位彦祖肯定要问，一个连代码都不会写，也不会读的纯小白，是怎么能做一个企业技术官号的运营，甚至还做得有所小成？

首先排除他帅，他虽然有点小帅，但肯定比不上在座的各位彦祖。

然后排除他天才，他虽然有点小聪明，但在绝对理性的 0 和 1面前都不足为外人道。

那是因为什么呢？今天小编我就揭秘一下，文科生的我，是如何让 AI 为我发声的！

# 01

小白视角的玩虾心得

OpenClaw 我很早就知道，也理解它很厉害，但门槛摆在那里。上周末我参加了两场龙虾线下沙龙，发现两个多月过去，还是有很多人被卡在了安装部署这里。

我自己装 OpenClaw 的时候也遇到了很多问题，基本上每一步都报错，最后都是靠复制报错代码丢给 AI 分析才解决的。

这对普通用户是最大的门槛，对技术同学来说是乐趣的东西，对小白就是纯折磨。所以，后来我电脑上装的 OpenClaw 都没怎么再用过，现在主力在使用的是腾讯自家出品的 QClaw。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=e2f5f870&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FZRhjO8xAWr5ibMNGcM7ibYYibqLEVumBBYUZPJN9NHncJ0qvyJKP5GA0B2cLVjnve9vf3DvJRNW9FIR2S1qVmvviao6QszMia1lhIFkHZuv2k7Xw%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg)

这是一个基于 OpenClaw 开源生态打造的本地化 AI Agent 助手，已于上周开启全量公测，无需复杂配置，三步即可上手，自带安全防护，支持微信直连绑定，内置多款优质国产大模型，现阶段也是完全免费使用，基本上前面提到过的痛点都可以靠它解决。

下载安装，扫码绑定，开始用，一共就三步，简单。而 OpenClaw 生态里日益严重的那些安全问题、Skills“投毒”攻击等等这些风险，纯小白可以说是完全防不胜防，为了不成为互联网上的肉鸡，也为了我的浏览器记录不被曝光，我只能忍痛告别“外地虾”。

# 03

人机协作 Vibe Writing

不同于编程领域下，AI 的突飞猛进，在写作方面 AI 的效果还是不够理想。

全篇多到飞起的“不是，而是”句式，莫名其妙的比喻，和非要结构化输出的文字，每一点都踩在读者的雷点上。

QClaw 目前的灵感广场里，也有写作相关的 Skills，但相对而言效果不够理想，所以我会更多在前置环节里加上自己的介入。

核心链路长这样：

1. QClaw 基于指令将参考资料归档，收集网络素材与我提供的素材
2. 提炼核心信息，我一般会要求它重点提炼矛盾冲突、反直觉判断等内容
3. 基于获得感前提，生成多个主题和结构化提纲，并说明为什么这么干
4. 协助我润色、压缩，改成不同平台的版本

不要期待 QClaw 或任意其他 Agent 能在写作方面给你惊艳，用好 AI 的一大要诀就是充分了解它的能力边界所在，就像汽车的辅助驾驶，是把方向盘完全交给 AI 还是有限度地放权，得到的结果可能是天壤之别。

在这个环节下，QClaw 是可以省去很多我的机械劳动的，而且当你降低期待值以后，反而时不时会有一些惊喜出现。

# 04

轻量化的 Vibe Coding 和流程自动化

我第一次被 AI 震撼到的场景，是给 Claude 发了一个表格转图片的想法，当时的场景是我觉得 Excel 的默认图片太丑，工作展示环节不好看。

然后 Claude 直接在浏览器里单开了一个小窗，现场写了一个 html 的代码，把我给它的数据做了分类、汇总、高亮和主题颜色等等。

当时我就仰天长叹一声，苍天啊，我们文科生的好日子终于来了！

最近我简单尝试了一些 Vibe Coding，把自己过往受限的痛点给解决了：

我有一个创业的想法——现在就差程序员了。

举个例子，我用 AI Vibe Coding 了一个小红书长文切图的本地工具，把文章转化成 json 语法贴到浏览器编辑框，然后点击刷新预览就可以看到结果，再点击批量下载就可以完成整个流程。

但这个工具对我来说还是有个痛点，文章越长，json 越复杂，改语法的时候就越费劲，而且整个流程的自动化还是不够极致。

于是，我把这个工具的 readme 文件发给了 QClaw，让它理解工具用法，我后续只需要把文字内容发给它，它自动完成转换 json、编辑、切图导出的全流程工作。
