# 话题背景

不知道大家有没有碰到过Token刺客的情况，最简单的操作需求、报错自查重试、上下文越滚越大 Token消耗哗哗的狂飙，看一眼余额才月初就不够用了！

**本期来看下鹅厂同学们都碰到什么样的Token刺客吧! （文末有奖）**

![图片](https://wechat2rss.bestblogs.dev/img-proxy/?k=f5d15bbc&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_jpg%2FpgebNmm1icyJu6V0jUJ2AMsdEr4RSiaBeP8psibVgWdjP3gcjteKT0skaP0FfibBayicNKIPXmcxmgRLkgv6eicX8hfSxELvMvIQ5e3Ftutt4rwico%2F640%3Fwx_fmt%3Djpeg%26tp%3Dwxpic%26wxfrom%3D5%26wx_lazy%3D1%23imgIndex%3D1)

##### tokenking-技术产品

> 上次输出原型本来只想让 AI 帮我改个前端组件的样式，顺手把整个src目录都喂进去了，心想“反正它聪明，自己找文件呗”。好家伙，它真去找了，把一堆i18n文案、mock数据全读了一遍，吐出来一堆根本不需要动的代码，一看记录：token消耗量直接爆炸，感觉像钱包被偷了。
>
>  不过最头疼的还是Agent跑偏，有时候它开始胡扯，我还抱着侥幸心理等它“自我修正”，结果越修越离谱，token蹭蹭涨。**现在我学会了一个字：断。发现不对劲立马掐掉，比月底看面板的时候心疼强。**
>

##### illidan-系统开发

> 让 AI Agent 帮忙重构一个组件，本来只想改个样式逻辑，结果它把整个文件读了一遍，又把相关的 hooks、utils、类型定义全扫了一圈，最后还贴心地帮我把 import 都重新整理了一遍——改动 5 行代码，烧了 3 万 token。**事后复盘发现，大文件 + 深层依赖引用是 token 黑洞。**

##### boey-技术测试

> 之前遇到的一次刺客是短指令 prompt 碰上了巨量的上下文，还叠加了模型切换。当时任务卡死了，我中断了任务然后换了一个模型说「继续任务」，结果这轮对话烧了非常多的 token，因为这条对话的上下文已经积压了几百条消息，全是之前反复读写文件积累的历史，我说继续的时候，agent 根本不知道继续什么，只能重新回顾上下文然后在噪音里尝试。
>
> **后来学会了上下文过长的时候就需要开新对话了，把关键的信息形成文件，并且不能用简短的模糊指令。**
>
> ![图片](https://wechat2rss.bestblogs.dev/img-proxy/?k=fe7fa12d&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_jpg%2FpgebNmm1icyLmLmeFB1WzabbbILvLzrhFxicjuBGmbTywPOarwW6CqDhibNOuArRdaBSUpia57bfv1IicgibvlWU9CsvlUficJiag7I2MN15DNs80bg%2F640%3Fwx_fmt%3Djpeg%26tp%3Dwxpic%26wxfrom%3D5%26wx_lazy%3D1%23imgIndex%3D6)

##### jery-客户端开发

> 我的 Token 刺客不是 Agent，也不是模型，而是那句： "顺便帮我看看还有没有别的问题。" 本来只是改一个 Bug，AI 开始一路检查整个模块、顺手优化代码、分析调用链、找潜在风险…… 回头一看，Bug 两分钟改完，Token 已经飞了。
>
> **现在学乖了：先把当前问题解决，再开新会话处理"顺便"的事情。 Token 和成功率都高不少。**

##### WinwinX-产品策划

> 我用 WorkBuddy 的时候，最有感的 token 刺客不是“大任务”，反而是一些**看起来很小的改动。**
>
> 比如我只是想让它帮我看一个需求相关的逻辑：改一下某个入口的文案、梳理一下埋点、确认某个接口字段有没有影响。结果 Agent 一启动，就开始把相关仓库、历史代码、接口定义、配置文件、甚至一些看起来八竿子打不着的文件都扫一遍。
>
> **最后我发现，真正要改的可能只有几十行，但前面“找上下文”已经烧掉一大截 token 了。**

##### Hang-技术测试

> **我自己踩得最深的坑：工具挂太多。**同时开着二十几个 MCP，每轮对话光工具 schema 就烧掉 3-5k token，什么活没干，钱先没了。后来强制自己只挂当前任务需要的工具，成本直接砍了一大半。 
>
> **第二个：上下文越滚越大。**Agent 跑长任务的时候，第 1 轮 2k token，第 20 轮可能 50k+。后面每一步的成本是前面的十几倍，但真正有用的上下文就最近三轮。解法是长任务拆段跑，做完一段开新 session，历史不带走。 
>
> **第三个：出错了让它自己重试。**这是最贵的一个习惯。AI 没有成本感知，它会一直试，每次重试还带着完整的失败记录，越试越贵。现在的规则是：同一个问题重试超过 2 次，停下来问我。

##### joyee-产品策划

> 用Agent帮我进行word的文件操作，比如把一些数据按照规定的格式梳理好放进word里，一个4-5页的word可以消耗20-30元，相比于其他操作，比如用同样的模型去进行数据整理输出为md文档（一般只需要2-3元），还是比较刺客的；所以感觉以后还是先梳理好信息输出md格式的文件，然后让更便宜的模型去进行更细节的文件操作会好点
