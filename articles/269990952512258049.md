——不用记命令、不用找专家的OS

TencentOS AI增强版预装了两个 AI 运维技能：

🔧 **全栈运维诊断专家**（TencentOS-expert）—— 9 大领域 24 项日常运维能力

💥 **内核宕机分析专家**（crash-expert）—— 内核崩溃自动化分析

都可以使用自然语言描述问题即可触发。

---

技能一：全栈运维诊断专家

24 个运维模块，覆盖磁盘、网络、性能、内存、安全、日志等 9 大领域。AI 根据你的问题自动匹配 1~3 个模块按需加载，不堆砌、不冗余。

### 你只需要这样说：



```
帮我看看磁盘空间哪里占得最多  
服务器网络延迟高，帮我排查一下  
生成一下CPU火焰图看看热点  
帮我做一下等保三级安全检查
```

AI 自动完成：**匹配模块** → **安装依赖** → **执行诊断** → **输出结论**

技能二：内核宕机分析专家

内核 crash 后的 vmcore 分析，一直是门槛最高的运维场景之一——需要内核经验、crash 工具链和归因能力。**内核宕机分析专家**把这件事做成了自动化流程：

| 能力 | 说明 |
| --- | --- |
| **全自动 7 阶段分析** | 环境检查 → 基线收集 → 崩溃识别 → 根因定位 → 补丁搜索 → 缓解评估 → 报告生成 |
| **全类型崩溃覆盖** | Hung Task、Soft/Hard Lockup、BUG\_ON、NULL 指针、OOM、SysRq 等 |
| **社区补丁关联** | 自动搜索上游 fix commit，检查发行版是否已修复 |
| **结构化报告** | Markdown + HTML 格式，含证据链和修复建议 |

### 你只需要这样说：



```
> 分析最新的 vmcore，定位崩溃原因
```

两个技能的关系

一个覆盖日常运维的"面"，一个深入内核崩溃的"点"：

|  | 全栈运维诊断专家 | 内核宕机分析专家 |
| --- | --- | --- |
| **定位** | 日常全栈运维 | 内核崩溃深度分析 |
| **覆盖** | 9 大领域 24 项能力 | 全类型内核崩溃 |
| **门槛** | 零命令基础 | 无需内核经验 |
| **输出** | 诊断结论 + 建议命令 | 结构化报告（MD + HTML） |

两个技能已预装在 TencentOS AI增强版镜像中，通过 WodeBuddy CLI 或腾讯云CVM可直接使用。

尝鲜使用

> 🖥️ 体验方式一：云服务器（CVM）上直接体验

## 适合有真实服务器环境、希望在生产或测试机上使用。

> 1、登录腾讯云控制台，创建 CVM 
>
> 2、镜像选TencentOS Server 4 for AI（Tencentos Server 4 for X86\_64  AI）
>
> 3、选择 CPU 或 GPU 实例 → 启动镜像
>
> 4、镜像已默认集成在codebuddy CLI中， 在codebuddy CLI中启用自然语言运维
