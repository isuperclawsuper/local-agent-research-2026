**@qing-客户端开发**▼

最近自己 Vibe Coding 做了一个 macOS 原生小工具，叫 AgentCrew。

平时用 Cursor、Claude、Codex 这些 AI 辅助开发时，最大的感受就是：不同模型真的各有各的强项。有的适合改代码，有的适合 Review，有的适合查 Bug 和做修复。

但现在大多数 IDE 里，这种跨模型协作还是得靠手动切，没法把“写代码 -> Review -> 跑测试 -> 失败修复”真正串成自动流水线。

所以我就顺着这个痛点，自己做了一个 AgentCrew。它是一个面向 macOS 的 AI + CLI 编排工作台，可以把 Cursor / Claude / Codex 和 git / npm / docker / ffmpeg 这些工具放到同一个可视化工作流里协作。

现在它可以自动拆任务、生成 Implement -> Review -> Fix -> Verify 流程，也支持测试、抓错、补 Patch，甚至能扩展到本地 CI/CD、批处理和运维任务。

我最喜欢的是，它不是简单再包一层聊天界面，而是真的想让不同 AI 和传统工具像“数字工人”一样协作起来。

目前还在持续打磨中，但这次 Vibe Coding 的体验很爽，也算是把“要是有这个工具就好了”真的做成了一个能跑的原型。
