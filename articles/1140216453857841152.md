1.为什么有这个？

ISUX团队在探索「AI × 设计」的过程中，陆续打造了不少好用的AI工具，也积累了大量实践经验，但这些成果散落在各处，新同事找不到、老同事记不住、好东西没人知道。我们需要一个统一的入口，把团队的 Al能力集中起来，让每个人都能快速找到并用上。

2.有什么？

目前已上架12款 AI工具，覆盖设计全流程：设计走查与还原对比、用户旅程图自动生成、AI 热力图分析、竞品设计分析、界面多尺寸极速适配、文案智能校准、新闻聚合、视频提取等。同时沉淀了9篇实践文章，从零基础技术入门到 AI Coding 工程化落地，帮设计师跨越技术门槛。

3.价值在哪？

让不会写代码的设计师也能享受 AI 生产力红利；让散落的团队 AI能力形成合力，避免重复造轮子；让好工具被看见、被使用、被反馈，形成正向循环。用AI 赋能设计全流程，让每个设计师都成为超级个体。

4.怎么做的？

借助 AI编码助手 CodeBuddy 从零搭建，纯 Node.js + 原生 HTML + Tailwind CSS，轻量易维护。支持深色模式、移动端适配、角色权限管理、AI生成封面、访客统计、New 上新提示等功能。从构思到上线，本身就是一次「设计师用 AI做产品」的最佳实践。

**@aero-产品经理**▼

用Vibe Coding搞了一个纯本地存储的提示词管理工具，我们每天都在产生大量的提示词（Prompts）。然而，大多数人正面临以下挑战：

资产散落：提示词记录在 Notion、记事本、甚至聊天记录里，难以查找。

版本管理难：微调一个参数后，旧的高质量 Prompt 就丢失了，缺乏迭代记录。

隐私风险：敏感的业务 Prompt 存储在第三方云端，存在泄露风险。

协作隔阂：优秀的提示词难以在团队中以标准化的形式分享和复用。

Al Prompt Manager 为此而生，为您提供一套完整的提示词生命周期管理方案。

三大核心亮点：

1. 三重颗粒度，精细化资产管理

场景 （Scene）：按业务维度分类（如：代码重构、文案润色、数据分析）。

提示词 （Prompt）：具体的任务条目。

版本（Version）：支持同一Prompt 的多版本并存，记录每一次迭代的闪光点。

2. 本地优先，坚守隐私底线

基于浏览器 IndexedDB 存储技术，您的所有数据均保存在本地：

物理隔离：数据不经过服务器，从源头上杜绝了隐私泄露。

离线可用：即使在无网络环境下，依然可以流畅编辑和查询您的资产库。

瞬时响应：本地数据库毫秒级查询，拒绝云端加载等待。

3. 一键导入导出，自由流转

我们深知协作的重要性。通过标准化的数据结构，您可以：

备份安枕无忧：支持全量导出为 JSON 格式，方便物理备份。

团队共享：将优秀的 Prompt 库导出分享给同伴，对方一键导入即可无缝衔接。
