今天，全新 Qoder 正式发布！这是一个以 Coding 能力为核心底座，面向所有人打造的智能体工作台。

告诉 Qoder 你想完成什么，它会理解上下文、制定计划、调用工具、执行并验证。整个过程随时可以查看、调整或接管。

全新的 Qoder 将会持续探索 Coding 能力在数字世界更高的天花板，不止于编程。

## Qoder 的这一年

2025 年 8 月，Qoder IDE 的第一个公开版本面向全球发布，短短一个月就收获了百万用户。

几个月后，Qoder CLI 和 Qoder JetBrains 插件陆续发布，Qoder 进入开发者习惯的不同工作环境。紧接着，数字员工 QoderWake 上线；Qoder Cloud Agents 则把 Agent 的运行环境搬到云端。

到今天，Qoder 累计全球用户超过 600 万，超 10 万家企业客户正在使用 Qoder。

感谢全球用户的支持和信任。在服务用户的过程中，我们也发现有三样东西已经变了。

#### 工作对象的转变：从代码工程，到智能体任务

过去打开一个工具，面对的是文件、目录、函数；现在你交代的是任务：把这份数据整理成报表、把这个想法做成能运行的原型、修改缺陷列表中的问题、排查昨晚那次超时。

代码依然存在，但它成了智能体工作的中间产物，不再是你直接操作的对象。以事为中心，是人与智能体最重要的协作界面。

#### 工作姿势的转变：从生产，到委派与验收

当智能体能独立完成一整个任务，人的动作也就变了。五个任务同时在跑，哪个需要你现在看一眼？哪个可以放着不管？哪个正在往错的方向走？

管理智能体任务，和编辑代码，是两种完全不同的界面诉求：描述与澄清一个任务、跟踪它的状态、验收最终结果——这些事，已经超出了“写代码做实现”本身。

#### 参与者的转变：从专业程序员，到更广泛的人群

代码是数字世界的通用语言，Coding 已经成为数字世界的通用能力。

需要“用软件的方式解决问题”的人，早已不只是程序员。他们目标明确，也能判断结果好坏——只是不该被要求先学会配置一套开发环境。所以我们的策略是：给不同的人最习惯、最顺手的形态，让产品形态不再成为你使用智能体的门槛，不懂代码不意味着你做不出好的产品。

作为你个人的智能体工作台，始终以编码智能体为核心引擎，从想法到实现，轻松搞定。因此，我们带来全新 Qoder。

## 全新的 Qoder 有哪些核心能力？

### 强大的模型调度能力

Qoder 内置全球顶尖的模型，同时提供强大的模型调度能力，不把用户绑定在单一模型上。熟悉模型的人可以按任务选择；不想花时间研究，也可以交给全新的Auto 智能调度引擎。Qoder 模型智能路由机制，会根据任务，在效果、速度和成本之间做出最恰当的选择。

![图片](https://wechat2rss.bestblogs.dev/img-proxy/?k=a8a1be9f&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_jpg%2FGicicSW0VicbiblURDPs6WQY639owRrr1JaDnfTYiasox2EpLE24Qm5TGGsgQpkAnGK2eIfPymNnm5G038IuPDmAUnfQxr3ibypIQ64OQxj3UafVU%2F640%3Fwx_fmt%3Djpeg%26from%3Dappmsg%26tp%3Dwebp%26wxfrom%3D5%26wx_lazy%3D1%23imgIndex%3D1)

### Harness：让复杂任务持续做下去

Qoder 采用业界最新的 Harness 技术，把这条长链路稳稳撑住——活再多、任务再长，也不容易中途走散：

* 自主 Agentic 循环够硬：擅长"读—改—验证—迭代"的长链路自治：自行检索代码库、跨文件编辑、运行测试，并根据真实结果自我纠错。
* 权限与安全边界清晰：分级权限模式 + 工具白名单机制，敏感操作必须显式授权。放手让它干，但不必担心它越界。
* 模型与工程一体化调优：内置海内外 SOTA 模型，每一款都做过深度适配；Harness 还与 Qwen 模型协同迭代，在长上下文处理、自动上下文压缩、工具调用准确率上形成端到端的优化优势。
* 会自我进化：支持跨会话长期记忆，周期性自我提炼技能——用得越久，越懂你的项目和习惯。

对用户来说，这意味着交给 Qoder 的任务可以更长、更复杂，来回沟通更少。

### 接入你的系统，AI 才真正懂你的工作

面向不同的任务场景和用户，Qoder还提供编程和通用两种模式，编程模式更适合开发者和代码相关任务，通用模式则面向更广泛的用户和场景，用户无需直接处理代码，也能借助Coding和工具能力完成任务。

在 Qoder 中，Goal 让 Agent 围绕明确目标持续工作，Plan 帮它先想清楚路径；记忆、本地项目和运行状态提供任务需要的背景；Browser Use、Computer Use 让它可以操作网页、桌面应用。

此外，通过接入 40+ 连接器、70+ 插件与 20K+ 技能，Qoder 能够打通你的工作系统——无论是代码仓库、项目管理、云服务还是内部工具，都可以作为上下文和工具直接融入 AI 的工作流。

### 从“你驱动它”，到“它提醒你”

现在，Qoder 会把这些值得关注的事情主动带到你面前，语音随口唤起，桌面伙伴常伴左右。它不只回应指令，更会主动带来任务进展、重要提醒与下一步建议。你依然是做决定的人，但你不必再是想起一切的人。

## 这只是开始

Qoder 桌面应用端今天发布，但这条路才刚展开。

我们的方向很清楚：让人必须介入的次数越来越少，同时让结果越来越可信。再往前，是任务与任务的协同、人与智能体的共同编排，以及把一次成功的工作固化成可反复使用的能力。

当 Coding 成为数字世界的通用能力，拥有一个 Coding Agent，就等于拥有把想法变成现实的能力。
