# 前言

近年来，基于Diffusion Transformer（DiT）的视觉生成模型几乎每一个关键部件都被重新审视过：tokenizer、attention、conditioning、training objective、latent autoencoder、text encoder……从 DiT 到 MM-DiT，从 REPA 到各种 rectified-flow recipe，大家都在问同一个问题：**怎样让 Diffusion Transformer 更快、更稳、更强？**

相比之下，Transformer 中最基础的 residual stream 长期被视为一个默认可靠的工程组件：每一层产生的更新被直接加回同一条隐藏状态主干，并沿深度继续向后传播。这种朴素的残差连接方式，几乎一直被默认继承了下来。

近期，南京大学机器学习与数据挖掘研究所（LAMDA）与阿里巴巴智能引擎团队联合提出 **Diffusion-Adaptive Routing（DAR）**，试图把这个长期被默认继承的设计重新放到扩散模型的语境下审视。论文的核心问题是：**在 denoising timestep 和 layer depth 不断变化的生成过程中，跨层信息是否仍然应该以固定权重持续累加？**

# 01

# 问题背景：

# 残差流为什么会成为瓶颈

标准 Transformer 的残差连接通常可以写成：

如果把它沿深度展开，第  层实际接收的是所有历史子层输出的直接累加。也就是说，早期层、中间层和最近一层的输出都会以固定系数 1 进入同一条 residual stream。

这种结构对于稳定训练非常重要，但在扩散模型中也引入了一个额外问题：不同 denoising timestep 对信息的需求并不相同。高噪声阶段更依赖全局结构和语义轮廓，低噪声阶段则需要恢复边缘、纹理和高频细节。如果跨层融合始终采用同一套 time-agnostic 的固定加法，模型就很难根据噪声阶段调整信息来源。

![image.png](https://wechat2rss.bestblogs.dev/img-proxy/?k=26acbdca&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FkN3t5R6pdz7xqZg6SS3EKMttlLK7ianJlicz5kQHfP1yM5uF6QRDAXvzPjbpFCr7dPyS5EARf2qYdh6pPoOb8RsOvYEvLSxGFvXmCicfcb6icnI%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg "标准残差路由在 DiT 深层呈现出三类症状：前向传播爆炸、反向梯度衰减和层间冗余。")

我们在 SiT-XL/2 上对 residual stream 做了系统诊断，沿 Transformer depth 与 denoising timestep 观察隐藏状态和梯度的变化。结果显示，标准残差路由在深层会出现三类明显现象：

1. **forward magnitude inflation**：隐藏状态幅值沿深度单调膨胀，从约 15.5 增长到约 1576，接近 100 倍；
2. **backward gradient decay**：反向梯度在前几层之后快速衰减，深层接收到的优化信号明显变弱；
3. **block-wise redundancy**：相邻 block 输出相似度长期高于 0.9，说明深层表示存在显著冗余。

这一现象与大语言模型中讨论过的 PreNorm dilution 有相似之处：residual stream 中的历史累积量越来越大，新层输出想要改变整体表示，就必须对抗不断膨胀的主干状态。对于 DiT 来说，这个问题还多了一个特殊维度，即 timestep。扩散模型不是单次前向预测，而是在多个噪声阶段逐步完成去噪，因此跨层信息路由本身也应具备时间自适应性。

![image.png](https://wechat2rss.bestblogs.dev/img-proxy/?k=b9f85b9f&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fmmbiz_png%2FkN3t5R6pdz5kRPprMNZfPEWiby4BxAzAGEF22j140CfJplf0JUroj7Mn2pnMsqOk99wyVLEfvbom9BU1s13lEATQkFUHnXP0jNzicRGKS5IQg%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg "SiT尝试学习出时间依赖的残差权重")

论文中进一步验证了这一点：跨层信息偏好并不是固定的，而是会随 denoising timestep 系统变化。对于没有显式 router 的 SiT baseline，我们在历史 residual source 上额外加了只用于测量的 scalar gates，并将这些 gate 初始化为 1，因此前向计算仍与原始 baseline 完全一致；随后读取 denoising loss 对这些 gate 的梯度，把它视为“如果 baseline 有一个等价 router，它会如何重加权历史 source”的反事实重要性。从图中可以看到，无论是浅层 block 3 还是更深的 block 13，SiT 的反事实 source importance 都会沿 timestep 发生变化，高噪声和低噪声阶段偏好的历史 source 并不相同。这说明标准 residual 虽然没有显式路由器，但其内部已经隐含了时间依赖的偏好。

这些观察凝聚成了我们的核心观点：**DiT中的信息聚合不应继续停留在固定、递增式的残差累加上，而应被设计为*****可学习、时间动态、非递增*****的路由机制。**

# 02

# DAR：依赖时间与空间的跨层信息路由

DAR 将 residual stream 看作一个沿深度维度的信息聚合过程。与其把历史层输出直接相加，不如让当前层对历史输出做一次 softmax 路由，决定哪些 source 更值得被使用。

这一思路受到 Attention Residuals [Kimi, 2026]的启发。AttnRes 将 Transformer 的 residual stream 重新理解为跨层历史表示的聚合，并用 depth-wise attention 替代固定残差递推。DAR 沿用了“在深度维度上选择历史 source”这一核心思想，但进一步把它放到扩散模型中，使路由权重能够感知 denoising timestep，从而适配不同噪声阶段的生成需求。

# 03

# Timestep awareness：

# 路由器必须知道当前噪声阶段

DAR强调路由权重需要随 denoising timestep 改变。论文比较了三种 query 设计：

其中  是第  层的可学习向量， 是 DiT 原有的 timestep embedding， 是第  层的 query projection。第一种 query 完全不显式感知 timestep；第二种把 timestep embedding 直接加进 router；第三种从上一层输出生成 query，而上一层 hidden state 本身已经通过 noisy input 和条件路径包含 timestep 信息。

实验结果表明，timestep awareness 不是某种trick，而是 DAR 成立的关键因素。以 400K iterations 为例，timestep-blind static variant 的 FID 为 11.51；dynamic query 和显式 timestep注入分别达到 8.10 和 7.97。也就是说，只有当 router 能够感知噪声阶段时，跨层路由才会显著优于固定累加。

这一结果也解释了 DAR 与 U-Net-like skip connection 的差异。U-Net skip 通常由人工预先规定浅层和深层之间的连接拓扑，而 DAR 保留 Transformer 原本均质堆叠的结构，只是在每一层内部引入可学习的 dynamic routing。连接不再是由设计者写死，而是在不同 timestep 下由模型自己分配。

# 04

# Chunked aggregation：

# 平衡跨层信息和显存开销

如果让每一层都访问所有历史 source，激活显存会随模型深度线性增长。DAR 因此采用 chunked aggregation：把已经经过的一段 sublayers 压缩成一个 chunk summary，同时保留当前 chunk 内尚未压缩的原始 source。这样，当前层不需要面对完整历史，而是在“过去 chunk 的摘要”和“当前 chunk 的细粒度输出”之间做路由。

这里的关键超参数是 chunk size。它决定了历史信息被压缩得有多激进：当 chunk size 很小，例如 ，模型几乎退化到 dense all-source routing，每个 sublayer 输出都进入 softmax，信息保留充分，但 router 面对的 source 太多，路由精度和计算开销都会受影响；当 chunk size 很大时，source 数量变少，但多个 sublayer 被压成一个 summary，历史信息会被过度压缩。也就是说，chunk size 本身存在一个典型的 bias-variance 式折中：太小会让路由空间过大，太大又会带来 summary distortion。

chunked aggregation 的代价可以拆成两部分，一部分来自 router 需要在多少个 source 上做选择，另一部分来自把多个 sublayer 输出压缩成一个 summary 带来的信息损失。对于 SiT-XL/2 这种 28 层、共 56 个 sublayer 的模型，在合理参数范围内，理论预测的最优 chunk size 大约落在 3.7 到 4.9 之间，正好对应实验里表现最好的 。这也解释了为什么 LLM 里的 AttnRes 会使用更大的 chunk：更深的 backbone 会把最优 chunk size 推向更大的区间，而当前 DiT backbone 的深度下，c4 更合适。

# 05

## 实验结果：更快收敛，也更好生成

在 ImageNet 256x256 上，DAR 同时改善了训练效率与最终生成质量。与 vanilla SiT-XL/2 相比，DAR static c4 在 ODE 采样下将 FID 从 9.67 降到 7.56，提升 2.11；在 SDE 采样下，无 classifier-free guidance 的 FID 进一步达到 6.92。更重要的是，DAR 可以用约 **8.75 倍更少训练迭代** 达到 baseline 的收敛质量。

论文还训练了参数量更接近 dynamic c4 的 SiT-Plus，以排除单纯扩大模型规模带来的收益。结果显示，即便在更高训练预算下，SiT-Plus 仍明显落后于 DAR，说明性能提升主要来自跨层路由机制，而非参数量增加。

与 U-Net-like skip 的对比也支持这一点。相比 U-DiT-L，DAR static c4 在 SDE + CFG 下 FID 低 0.77，同时只使用约 0.83 倍参数；相比 U-ViT-H/2，DAR dynamic c4 在 ODE 下也进一步降低了 FID。DAR 的收益并不是简单增加连接密度，而是让连接方式能够随深度和 timestep 自适应变化。

# 06

# 与 REPA 叠加：

# 一个优化表示目标，一个优化信息流

REPA 是近期用于加速 DiT 训练的代表方法，它通过把 DiT hidden states 对齐到预训练视觉表征，改善中间表示的学习质量。我们证明了REPA和DAR是正交的。实验显示，加入 REPA 后，DAR 仍然能继续带来增益：

1. 100K iterations：SiT + REPA 的 FID 为 9.89，DAR + REPA 降到 7.09；
2. 200K iterations：SiT + REPA 的 FID 为 6.89，DAR + REPA 降到 5.92；
3. DAR + REPA 在 100K 时已经超过 REPA alone 在 200K 的结果。

这组实验结果成功证明了DAR是一个足够解耦的方法，使用DAR并不会与REPA产生拮抗反应。我们也希望DAR 未来可以与更多 DiT 加速方法、蒸馏方法和 post-training recipe 组合，成为生成模型 backbone 中一个更通用的结构组件。

# 07

## 后训练与蒸馏：

## 在 Qwen-Image 上保留更多细节

除了 ImageNet 预训练，论文还将 DAR 应用于大规模 T2I 模型的 post-training。具体来说，研究者将 DAR 插入 Qwen-Image 的 MM-DiT backbone，并进行 Distribution Matching Distillation。

![image.png](https://wechat2rss.bestblogs.dev/img-proxy/?k=ee3e55e3&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_png%2FkN3t5R6pdz4pLP74Zs1vvlYwU9kHnqGMokLOPB63xSlwTZngJNCBDkkkHmyQ0HT2GeLg2wHqq4V4tm4FOTozjPDVOMFwYlibtN34Fx1Xc6DE%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg)

Few-step distillation 往往容易损失高频细节，也更容易受到训练不稳定性的影响。实验结果显示，DAR 能帮助蒸馏后的模型保留更清晰的边缘和纹理。对于这类需要在少步采样中尽量保持图像质量的场景，跨层信息流的改善会直接反映到最终视觉细节上。

# 08

## 结语：

## 残差流成为 DiT 的新设计范式

这篇工作的意义不只是提出一个新的 residual 替换模块。更重要的是，它把 Diffusion Transformer 中长期被视为默认工程细节的 residual stream，重新定义为一个值得系统研究的架构变量。

在标准 DiT 中，所有历史层输出被固定权重累加，模型很难根据不同噪声阶段选择真正需要的信息。DAR 则用可学习、时间动态、非递增的跨层聚合替代固定残差相加，使每一层都能根据当前 denoising 状态决定信息来源。

从实验结果看，DAR 在 ImageNet 256x256 上将 SiT-XL/2 的 FID 从 9.67 降到 7.56，并以 8.75 倍更少训练迭代达到 baseline 收敛质量；叠加 REPA 后，还能在早期训练阶段带来约 2 倍加速。在后训练和 few-step distillation 中，它也能帮助模型更好地保留细节。

对于扩散模型而言，这提示了一个可能被低估的方向：模型性能不只取决于每一层内部如何计算，也取决于不同层之间的信息如何流动。残差流并不是default choice，而是生成模型架构中可以被学习、被调节、也值得被重新设计的一部分。
