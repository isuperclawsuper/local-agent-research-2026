**接入前准备**

你需要两样东西：

* 一只已经活蹦乱跳的🦞
* 扣子罗盘的令牌和空间ID——登录 coze.cn/loop，获取服务访问令牌和扣子罗盘空间ID

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=eb5f216d&u=https%3A%2F%2Fmmbiz.qpic.cn%2Fsz_mmbiz_jpg%2FYXg9pjicEkwmKlPUZfnyH05NZSCm2naYRGjExwXkCXHgpCLZ9P2eOLdEcqCBR12ysOPSz9y9icRSv74QmntXajrs10QUicswtAgqHtecw5VdSs%2F640%3Fwx_fmt%3Djpeg%23imgIndex%3D8)

详细步骤参考：<https://docs.coze.cn/cozeloop/openclaw_trace_report>

**第一步：一键安装插件**

打开终端，执行以下命令，按提示输入你的令牌和空间ID即可完成安装和配置：

```
npx @cozeloop/openclaw-cozeloop-trace-onboard-cli install
```

安装器会自动完成插件下载、配置写入和重启，只需要跟着提示走就行。

**第二步：验证插件**

安装完成后，通过以下命令查看插件状态，确认 openclaw-cozeloop-trace 为 loaded：

```
openclaw plugins list
```

就这么简单，搞定！
