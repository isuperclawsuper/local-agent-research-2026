开启人和 Agent 协作新方式

今天，扣子 3.0 正式上线，扣子手机端 （iOS / Android）、电脑端（Mac OS / Windows）、网页端（coze.cn）三端全量更新。

这一次，扣子带来了全新电脑端，扣子 App 也全面升级，我们把 Agent 带进了更完整的工作现场：你可以在网页端创建和管理任务，在桌面端连接本地文件，也可以在手机上用扣子 App 推进任务、继续调度 Agent，甚至“遥控”操作电脑。

过去的这段时间，很多用户用扣子完成日常工作、每天执行特定任务。但当任务从一次回答走向持续推进，单个 Agent 往往需要更多协作机制，像团队一样：有人做调研，有人写方案，有人分析数据，有人开发……每个项目也需要持续的上下文、稳定的项目空间，以及随时能接上进度的工作环境。

如何让不同职能的 Agent 被灵活调用，并在真实项目里和大家一起协作，这就是扣子 3.0 想回答的问题。在升级后的扣子中，你可以创建项目，召集不同 Agent ， 完成从想法、讨论到执行和交付，让人和 Agent 像真正的团队一样一起工作。

如果你正在探索人和 Agent 协作的新方式，不妨从扣子开始，启动你的新一代 AI 团队。

扣子本身就是一个开箱即用的 Agent 伙伴，你可以直接和它对话，让它帮你理解任务、推进工作。以往的日程、邮箱、长期记忆和云电脑/云手机，都是扣子基础的满配能力，调研、创作、数据分析等办公任务，都可以交给扣子来完成。

目前扣子已支持切换模型，除了选用主流模型，也能接入自己订阅的模型，欢迎大家尝试。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=06f8eff7&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_png%2FWNG6TQDAicNemHN4Wo8LqHtD2K0DoXwEPL0ydhjJXDYLibnkiaODxjO7XPJ9yfJaCv9ticLIcXCicBibmrV0yyZ1avDaHEUgMEePBvI84maZLqK8E%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D2)

升级后扣子3.0的页面

但在扣子 3.0 中，Agent 不再只有一种形态。在网页/电脑端，或是手机 App 上，你都能随时添加 Agent，组建自己的 Agent team。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=c1b27271&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_png%2FWNG6TQDAicNecFe8iaAUniawXy4oyLzaOCXZuptbo3v66oqkQRj6668zMS6JFFxFoHOibSTcrJ92KBEbuLLp2asnB9HWqOOeVia7X7DxH0GSGo7M%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D3)

对于已经在本地使用 Claude Code、Codex CLI、OpenClaw 的朋友，现在也可以把它们接入扣子。接入后，这些本地 Agent 不再只是停留在各自的工具里，而是可以进入扣子的同一个项目空间，和其他 Agent 一起围绕同一个目标协作推进。

同时，它们也可以在扣子的多端里被随时调度。无论你在网页端、桌面端，还是打开扣子 App，都可以在授权范围内调度这些本地 Agent。比如打开扣子 App，远程调用你的Claude Code、Codex CLI 处理指定的本地文件，开放空间比想象中的更大。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=6df8be83&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fsz_mmecoa_jpg%2FWNG6TQDAicNd3iaFP8NFnpAsicD4IDy6MUP0V0YPWnXtJoytO9UJKrNKAjffJgc9IwoTjjbXibcYicNicRhLQKPT19kCpXO5G4KyGqIVfbib1ja41A%2F640%3Fwx_fmt%3Djpeg%26from%3Dappmsg%23imgIndex%3D4)

如果你希望 Agent 长期在线、持续协作，可以新建云端 Agent 。云端 Agent 运行在扣子提供的云电脑中，不需要配置环境等复杂操作，长期稳定在线。我们支持扣子原生 Agent、OpenClaw、Claude Code 和 Codex CLI 等主流框架，根据任务类型随心选取。

此外，根据不同工作场景，我们也提供职业模板，快速创建一个更贴近具体任务的 Agent。

比如投资顾问、自媒体达人、调研分析师、法务顾问等职业模板，都内置有专业技能包，让 Agent 从一开始就带着明确的任务语境进入工作。你只要选择对应场景，就能一键创建“专家助手”。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=698d96ef&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_png%2FWNG6TQDAicNdesOfYByicSiaunUSbQZlhnrfZWHic9I9mTWNLPN6oBrA34xx2siaZH87Wb80Iibch2NKsTNiacuMmRKK6Q2fH4ic11SCMTDdqzQ5d7U%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D5)

过去，这些 Agent 可能分散在本地、终端或不同工具里；现在，它们可以在扣子中被统一调度。对开发者和 AI 深度用户来说，你的 Agent 伙伴现在有了更好协作的平台，也有了随时调用的入口，你可以根据任务需要，组建自己的 Agent 团队。

目前选择职业模版创建、新建云端 Agent 为个人高阶版及以上会员权益，欢迎大家体验。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=0ae33792&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fsz_mmecoa_png%2FWNG6TQDAicNcHicnL23cDPKk8A0JVmiaOYbPltibOTpnBHcM3S39mwQTetaIL1VctkzUYN5KM4Mo94pqgAEebE0ZpdH8yrCFcfKATOjKiaeO7A9o%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D6)

有了 Agent 队伍之后，更重要的问题是：它们如何一起工作？在扣子 3.0 中，人与 Agent 的协作将在项目空间中进行。

项目是一个独立的任务管理空间，可以容纳目标、成员、Agent、文件和过程产出，让复杂任务在同一个上下文里推进。你可以把它理解成一个面向 Agent 协作的工作室：人负责设定目标、判断方向和确认结果，Agent 负责各自擅长的环节，并围绕同一个目标接力。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=ef9f3172&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fsz_mmecoa_png%2FWNG6TQDAicNeYZszHRERVHcvXgHicIdfoJfTK53TichLdWWzO53oKkOQArZ4iaTwmY0O0uCkdEGaIOHJF7J1JN58XOKDm5oEdH8HYI5HLTRhLwk%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D7)

在一个项目里，你可以调度多个 Agent，也可以邀请团队成员一起加入，让人和 Agent 围绕同一个目标分工协作。这不是多开几个聊天窗口，而是把任务、上下文、过程记录和产出沉淀在同一个项目空间里，让复杂工作可以更清晰地推进。

比如准备一场发布会，你可以创建一个发布会项目，让调研 Agent 分析市场动态，运营 Agent 拆解活动任务，传播 Agent 准备内容节奏和宣发素材；团队成员则一起补充判断、确认关键节点。在这个过程中，Agent 不再只是某个人手边的助手，而是项目里的协作成员。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=e348bf12&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_png%2FWNG6TQDAicNe4aqZTzkg0VylZVqVL5uDQNobKrwKxuy0AUXmjDiaVoLfCBReKWwomHvIibtanOxANdPibolrrI6vDzAIPWghpJseUlt04Z4Hnhs%2F640%3Fwx_fmt%3Dpng%26from%3Dappmsg%23imgIndex%3D8)

项目能力也会进入更具体的创作场景。

扣子3.0中，扣子编程能力与主对话已打通。通过创建编程项目，能实现多人协作完成开发，你可以从一个想法开始，多人协作开发网页、App、小程序，比如让设计师调整风格、研发补充功能逻辑、运营修改文案……

创建的编程项目会同步到扣子编程体系中，打开扣子编程（code.coze.cn）即可看到，后续可继续开发、部署和管理。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=85713c9d&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_gif%2FWNG6TQDAicNeBicSichXBxNAJr8zSCibNuTjogU38rDLH2NJAPo9zU5QRKFFU2w9bGJa5JuMtrQW5LIRDvItwGjAwFuHNtOSdPFRJ088kyvdZDY%2F640%3Fwx_fmt%3Dgif%26from%3Dappmsg%23imgIndex%3D9)

视频项目搭载 Seedance 2.0，支持从剧本、分镜，到视频、音乐、续集生成的对话式迭代。生成之后，你还可以继续对话剪辑、或手动操作，并导出剪映工程文件。

目前已经有很多专业创作者用扣子视频 Agent ，创作出精彩的 AI 漫剧和系列短剧。在扣子3.0内测阶段也有用户创作了很有意思的短片——《当乔布斯在2026复活》。只要你有想法，就能在扣子视频上尽情发挥创作。

视频项目的多人协作能力将在后续上线，欢迎大家持续关注。

本次升级后，打开手机扣子 App 都能同步完成视频项目、编程项目。无需复杂编码，对话即可开发、完成部署；也不用繁琐编辑，边聊就能边生成视频。真正的“口喷式”完成任务，现在触手可及。

一支好用的 Agent 团队，每个业务需要有“专家”级别的角色，才能更专业地完成任务。因此，扣子升级了技能商店，提供专家级技能包和权威数据集，让 Agent 可以精准进入具体任务。

比如A 股投资分析技能包，能围绕板块热度、量化股票分析等任务提供分析起点；全能法务助理技能包，会支持法律咨询报告、类案检索、法律备忘录等任务；科研助理技能包，则可以围绕专业论文数据库，为科研任务提供支持。

技能商店也支持按金融、自媒体、法律、电商、互联网、科研等方向筛选。你可以根据自己的业务，一键添加对应技能包或具体技能，让 Agent 先拥有更贴近行业语境的能力组合。

AI 要真正参与工作，需要更靠近真实的工作现场。当扣子电脑端、手机 App、网页端全面联动后，你将在扣子感受多端协同的工作体验。

在获得授权的前提下，Agent 可以处理你本地电脑里的文件，读取、理解并生成相关内容。安装桌面端并连接个人电脑后，你可以通过手机端，远程处理个人电脑中的本地文件。

这意味着，任务不必被设备打断。你可以在电脑上创建一个编程项目，也可以打开手机在扣子 App 查看进度、继续推进开发；你可以在桌面端处理本地文件，也可以通过手机端远程控制电脑、打开整理文件。

![](https://wechat2rss.bestblogs.dev/img-proxy/?k=9b64c561&u=https%3A%2F%2Fmmecoa.qpic.cn%2Fmmecoa_jpg%2FWNG6TQDAicNfOagcI7QTWOmfibicFYgVRdSIOQU3E9425msrXaN7KLLPBF9wpDXoK46hFd4HePTibo4UM1eRQ0rdQzpddrOqDfqicN4INm86B9T8%2F640%3Fwx_fmt%3Djpeg%26from%3Dappmsg%23imgIndex%3D14)

对很多人来说，灵感和任务并不只发生在工位上。可能是在通勤路上想到一个产品想法，也可能是在外面突然要处理电脑里的一个文件，我们希望让 Agent 在真实的工作场景中完成任务，在你需要的时候出现，在不同设备之间持续接力。扣子通过三端协同，让你灵感随时能落地，任务持续不掉线。

在扣子 3.0， AI 团队协作方式有了全新的架构：

Agent 可以被创建、接入和随时调度；任务可以被放进项目中拆解、分配和沉淀；行业技能包可以为复杂任务提供更专业的能力起点；扣子的网页端、桌面端和手机 App 端，则让 Agent 有机会与你的文件、本地设备和真实工作场景接通。
